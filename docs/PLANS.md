# PLANS.md — 계획 수립 규약

계획은 일급 아티팩트입니다. 복잡한 작업은 저장소에 실행 계획을 남기고 진행/결정 로그를
기록합니다. 에이전트가 외부 상황에 의존하지 않고 작업할 수 있게 합니다.

## 계획 규칙

- **작은 변경**: 임시·간단한 계획만으로 작업. PR은 짧게.
- **큰 변경**: 아래 템플릿으로 `docs/exec-plans/active/<slug>.md` 작성 후 작업.
- 계획이 완료되면 `docs/exec-plans/completed/`로 이동.
- 진행 중 상태(진행률, 차단, 결정)는 해당 계획 파일 안에 갱신.

## 실행 계획 템플릿

```markdown
# 실행 계획: <제목>

- 상태: IN_PROGRESS | BLOCKED | DONE
- 생성일: YYYY-MM-DD
- 완료 기준: (완료를 판정하는 명확한 기준)

## 배경

## 단계

- [ ] 1. ...
- [ ] 2. ...

## 진행 로그

- YYYY-MM-DD: (결정/진행 사항)

## 결정 기록 (ADR)
```

## 기술 부채

- 알려진 기술 부채는 `docs/exec-plans/tech-debt-tracker.md`에 기록.
- 계획 중 새 부채가 보이면 즉시 트래커에 추가.
